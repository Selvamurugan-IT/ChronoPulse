# ⏱️ ChronoPulse — Date & Age Calculator

ChronoPulse is a high-precision, real-time Date & Age Calculator web app with dynamic tickers, countdown timers, date difference modules, and age calculations.

## ✨ Features
- **⚡ Real-Time Live Ticker**: Millisecond-accurate countdown with visual progress bar.
- **🎯 Target Presets**: One-click quick presets (New Year, Christmas, Custom Targets).
- **⇄ Date Difference**: Calculate exact days between any two dates.
- **➕ Add / Subtract Days**: Easily add or subtract duration from a base date.
- **🎂 Age Calculator**: Precise age breakdown in Years, Months, and Days.
- **📱 Fully Responsive**: Custom dark UI optimized for desktop and mobile screens.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Variables, Modern Grid & Flexbox)
- **JavaScript (ES6+)**
- **Canvas Confetti API**

## 🚀 How to Run Locally
1. Clone this repository or download as ZIP.
2. Open `index.html` directly in any modern web browser.
