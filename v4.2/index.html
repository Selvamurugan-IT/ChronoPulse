JSON backup & restore

A backup is a file on this device containing your profile, countdowns, events, goals, habits, tasks, check-ins, focus history and settings. It is not uploaded anywhere.

CSV export

UTF-8 with a byte-order mark so Excel shows accents correctly. Values that start with = + - or @ are prefixed with an apostrophe so spreadsheets cannot run them as formulas.

Moving data between devices

Backups are plain files; ChronoPulse does not sync automatically. To move from laptop to phone: export a backup here, send the file to the phone (cloud drive, email to yourself, USB or Bluetooth), open ChronoPulse on the phone, and choose Import / restore. Use Merge to combine with data already on the phone, or Replace to make the phone match the file.

      A reminder sound plays only while ChronoPulse is open on screen. When the app is closed, in the background or the phone is locked, your phone's own notification sound is used, because a web app cannot change it. Your file stays on this device and is never uploaded.

      Notifications are optional. ChronoPulse has no server, so it can only alert you while it is running: open on screen (a message inside the app) or in the background (a system notification, if your device keeps the app alive). It cannot wake a closed app, and delivery is never guaranteed: your browser, battery saver or phone settings can delay or block it. For event alarms that must work while the app is closed, use the calendar button on an event to add alarms to your phone's calendar app.
